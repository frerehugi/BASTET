# CCC-Fragenkatalog mit fachübergreifender GdB/MdE-Kalibrierung

Strukturiert die Kanadischen Konsenskriterien (CCC) in abfragbare Einzelpunkte und ordnet jedem Punkt eine Kalibrierungsreferenz aus einem verwandten Fachgebiet zu (Neurologie, Kardiologie, Psychiatrie, Neuropsychologie, Schmerztherapie). Grundlage für den strukturierten Fragenkatalog in BASTET/BASTET · Doc — ersetzt nicht die Fließtext-Anamnese, ergänzt sie um eine geprüfte Struktur.

## 1. PEM (Post-exertionelle Malaise) — zwingendes Leitsymptom

| Abfragepunkt | Ausprägungen |
|---|---|
| Auslöseschwelle | leichteste Alltagsbelastung / mittelschwere Belastung / nur starke Belastung |
| Latenz bis Verschlechterung | sofort / Stunden / 1–3 Tage (typisch) |
| Erholungsdauer | Stunden / Tage / >1 Woche / >1 Monat |
| Betrifft auch kognitive/emotionale Belastung? | ja/nein |

**Kalibrierung**: Kein direktes Analogon in anderen Fachgebieten — PEM ist ME/CFS-spezifisch. Dient primär der CCC-Erfüllungsprüfung, nicht direkt der GdB-Bemessung. Ausprägung/Erholungsdauer fließt aber in die Einstufung nach 3.7 (soziale Anpassungsschwierigkeiten) ein: je kürzer die belastungsfreie Zeit zwischen Einbrüchen, desto eher "schwere Störung".

## 2. Fatigue / Alltagsfunktion (Bell-Score-Logik)

| Abfragepunkt | Ausprägungen |
|---|---|
| Arbeitsfähigkeit | voll / reduziert (Prozent, falls bekannt) / arbeitsunfähig |
| Alltagsverrichtungen | selbstständig / mit Unterstützung / bettlägerig-nah |
| Bell-Score (falls erhoben) | 0–100 |

**Kalibrierung — Fachgebiet Neurologie (Hirnschäden, VersMedV 3.1.1, Gesamtbewertung)**:
- geringe Leistungsbeeinträchtigung → GdB 30–40
- mittelschwere Leistungsbeeinträchtigung → GdB 50–60
- schwere Leistungsbeeinträchtigung (weitgehender Verlust der Selbstständigkeit) → GdB 70–100

Diese generische Hirnschäden-Skala eignet sich als Kalibrierungsanker für den globalen Funktionsverlust, unabhängig vom Einzelsymptom — siehe `neurologie-vergleichsfaelle.md`.

## 3. Schlafstörung

| Abfragepunkt | Ausprägungen |
|---|---|
| Art | nicht erholsamer Schlaf / Ein-/Durchschlafstörung / Tag-Nacht-Umkehr / Hypersomnie |
| Auswirkung tagsüber | keine relevante / spürbar / erheblich (Tagesschläfrigkeit) |

**Kalibrierung — Fachgebiet Pneumologie/Schlafmedizin (VersMedV 8.7, Schlafapnoe-Syndrom)**: nur lose Analogie (anderer Pathomechanismus), aber die dortige Bewertungslogik — Ausprägung + Therapieerfolg bestimmen den GdS — ist strukturell übertragbar. Bei ME/CFS wird die Schlafstörung in der Regel nicht separat bewertet, sondern fließt in die Gesamteinschätzung nach 3.7/18.4 ein.

## 4. Schmerzen (mind. 2 von: Muskel-, Gelenk-, Kopfschmerz neuen Typs, Halsschmerz, Lymphknoten-Druckschmerz)

| Abfragepunkt | Ausprägungen |
|---|---|
| Lokalisation(en) | Muskeln / Gelenke (ohne Schwellung/Rötung) / Kopf (neuer Typ/neues Muster) / Hals / diffus |
| Schmerzcharakter | belastungsabhängig / dauerhaft / wechselnd |
| Therapieansprechen | gut / teilweise / therapieresistent |

**Kalibrierung — Fachgebiet Neurologie (Polyneuropathie, VersMedV 3.11)**: bei neuropathischem Charakter (Kribbeln, Brennen, Dysästhesien) real dokumentierter Fall mit Kraftminderung + Gangunsicherheit + therapieresistenten Schmerzen → **Einzel-GdB 30** (siehe `schmerz-neuro-kardio-erweiterung.md`).
**Kalibrierung — Schmerztherapie (interdisziplinär, kein eigener VersMedV-Punkt)**: bei funktionellem/somatoformem Schmerzbild ohne ausreichende körperliche Erklärung (Fibromyalgie-Referenzfall) → Bewertung über 18.4/3.7, nicht gesondert neben der ME/CFS-Gesamteinschätzung.

## 5. Neurokognitive Symptome (mind. 2 von: Konzentration, Kurzzeitgedächtnis, Wortfindung, Informationsverarbeitung, Reizüberempfindlichkeit, Ataxie, Muskelschwäche)

| Abfragepunkt | Ausprägungen |
|---|---|
| Konzentration/Gedächtnis | keine / leicht / deutlich (alltagsrelevant) |
| Wortfindung | keine / gelegentlich / häufig, kommunikationsrelevant |
| Reizüberempfindlichkeit | keine / Licht / Geräusche / beides |
| Gang-/Koordinationsstörung | keine / leicht / deutlich (Hilfsmittel nötig) |
| Neuropsychologische Testung vorhanden? | ja (Ergebnis) / nein |

**Kalibrierung — Fachgebiet Neurologie/Neuropsychologie (VersMedV 3.1.2, kognitive Leistungsstörungen/Aphasie-Tabelle)**:
- leicht (z. B. Restaphasie-analog) → GdB 30–40
- mittelgradig (deutliche Kommunikations-/Alltagsstörung) → GdB 50–80
- schwer (globale Aphasie-analog) → GdB 90–100

**Kalibrierung — Koordinations-/Gangstörung**: analog Kapitel 3.1.2 Koordinationsstörungen zerebellarer Genese, GdB 30–100 je nach Ausmaß, sowie Parkinson-Tabelle bei Verlangsamung/Gleichgewichtsproblemen (GdB 30–40 / 50–70 / 80–100).

**Wichtiger Hinweis für Ärzt:innen**: Eine formale neuropsychologische Testung (falls vorhanden) liefert objektivierbare Anhaltspunkte, die eine Einordnung präzisieren — bei ihrem Fehlen ist die Einschätzung entsprechend vorsichtiger zu formulieren.

## 6. Autonome/neuroendokrine/immunologische Symptome

| Abfragepunkt | Ausprägungen |
|---|---|
| Orthostatische Beschwerden | keine / Schwindel im Stehen / Präsynkope / Synkope |
| Herzfrequenzanstieg im Stehen dokumentiert? | ja (≥30 bpm / auf ≥120 bpm) / nein / nicht getestet |
| Temperaturregulation | unauffällig / gestört (Kälte-/Wärmeintoleranz) |
| Gastrointestinal | unauffällig / Reizdarm-artige Beschwerden |
| Infektanfälligkeit/neue Unverträglichkeiten | keine / vorhanden |

**Kalibrierung — Fachgebiet Kardiologie (VersMedV Kapitel 9, Herzleistungstabelle, leistungsbasiert)**: keine wesentliche Beeinträchtigung → GdB 0–10; Beschwerden bei mittelschwerer Belastung → GdB 20–40; höhere Stufen bei Beschwerden schon bei leichter Belastung/in Ruhe. **POTS-spezifisch**: kein eigener VersMedV-Punkt, Einordnung über diese Kapitel-9-Logik oder als autonome CCC-Kategorie über 18.4 — siehe `schmerz-neuro-kardio-erweiterung.md`. Diagnosekriterium: HF-Anstieg ≥30 bpm (bzw. auf ≥120 bpm) binnen 10 Min. nach Aufstehen/Kipptisch, ohne Blutdruckabfall, seit ≥3 Monaten. Nur bei ca. 30 % der ME/CFS-Betroffenen formal nachweisbar — fehlender Nachweis schließt orthostatische Intoleranz nicht aus.

## 7. Psychische Komorbidität (eigenständig, nicht nur Symptom-Begleiterscheinung)

| Abfragepunkt | Ausprägungen |
|---|---|
| Eigenständige psychiatrische Diagnose? | ja (welche, z. B. F32/F33/F43.2/F41.1) / nein, nur reaktive Belastung |
| Fachärztlich gesichert? | ja/nein |

**Kalibrierung — Fachgebiet Psychiatrie (VersMedV 3.7, volle Tabelle)**: leichtere Störungen 0–20; stärker behindernde Störungen 30–40; schwere Störungen mit mittelgradigen sozialen Anpassungsschwierigkeiten 50–70; schwere Störungen mit schweren sozialen Anpassungsschwierigkeiten 80–100 — siehe `nervensystem-psyche-herz-gdb.md`. **Wichtig**: bei eigenständiger psychiatrischer Diagnose als Komorbidität (nicht bloß Symptom der ME/CFS-Gesamtsymptomatik) kann diese zusätzlich in die Gesamt-GdB-Bildung einfließen (keine Addition, aber möglicher Erhöhungsfaktor, siehe Gesamt-GdB-Prinzip).

## 8. Medikation

| Abfragepunkt | Warum relevant |
|---|---|
| Aktuelle Medikation (Wirkstoffgruppen) | Symptomkontrollierende Medikation (z. B. Betablocker bei POTS, Schmerzmedikation, Stimulanzien) kann den *aktuellen* Befund maskieren — relevant für die Einordnung "wie stark wäre die Beeinträchtigung unbehandelt" |
| Therapieansprechen | gut / teilweise / kein Ansprechen — schlechtes Ansprechen trotz adäquater Therapie stützt tendenziell eine höhere Einstufung |

## 9. Dauer und beruflicher Kontext (Rahmenbedingungen, kein CCC-Punkt)

| Abfragepunkt | Ausprägungen |
|---|---|
| Symptomdauer | <6 Monate (GdB-Voraussetzung noch nicht erfüllt) / ≥6 Monate |
| Beruflicher Zusammenhang | keiner / Gesundheitsdienst-Wohlfahrtspflege-Labor-Kontext (BK-3101-relevant) |
| BK-3101-Status (falls Berufsbezug) | nicht gemeldet / gemeldet, offen / anerkannt |
